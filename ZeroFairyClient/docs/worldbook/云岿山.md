# 云岿山
当年莱姆尼安空洞附近有一个奇异之物，此物拥有吸收生物体内以太的异能，触碰过它的常人皆无法承受而遭到它的反噬，直到一位高人为了不让它继续害人，使用超乎常人的以太掌控力抑制了此物的肆虐，但高人游历四方，依然没能找到杀镇之法，只能在一座偏远的山上将这异物打造成了一把利剑，起名为青溟剑，云岆山这一门派也自此成立。之后这位高人的道统也得到了传承，他主张的济世度人的理念中留下了一些修炼之法，诸如移形换位、操纵兵器、化解疾病、通灵异兽等，也让云岆山成为盘踞一方的势力。

云岆山第十一任门主收留了天赋异禀的仪绛和仪玄姐妹，选定仪绛为下一任门主。旧都陷落期间，云岆山集体出动讨伐作乱的以骸，第十一任门主出动了青溟剑，因过度使用青溟剑的力量而被剥夺五感变成废人，临终前将青溟剑传给仪绛，为了克服青溟剑的副作用，仪绛和仪玄开始研究术法"青溟鸟"。

然而不久之后，仪绛还是为了保护仪玄不得不使用青溟剑的力量，从而五感受损，最终为对抗大量以骸解放青溟剑的全部力量，在一片白光中五感和记忆尽失，最终被庞大的能量反噬形神俱灭，仪玄赶到时，现场只剩下青溟剑和仪绛的发簪。

仪玄担任第十三任门主后，并没有使用青溟剑，依然在不断钻研克服青溟剑的术法，凭自身力量成为了虚狩级别的强者。仪玄收了橘福福、潘引壶、叶释渊和叶瞬光等人为徒，其中天赋最高的叶瞬光被青溟剑选为下一代剑主，仪玄为了防止悲剧重演，将早年用来压制青溟剑反噬的剑归赠与小光，并以修为由将小光排除在危险任务之外，即使这会让小光有挫败感，即便这会使用一些小小的谎言，仪玄和其他同门师兄弟依然尽心尽力地保护着小光，直到仪玄能够找到万全解法的那一天。
